# Pre-Submission Checklist

- [ ] Verify the full name, group, and variant number in `README.md` and the report.
- [ ] Run `npm install`, `npm run build`, and `npm test`.
- [ ] Run `ci.bat` on Windows or `bash ./ci.sh` on a Unix-like operating system.
- [ ] After running `npm install`, verify that `package-lock.json` has been created and commit it to the repository.
- [ ] Verify that `dist/`, `node_modules/`, and secrets are not tracked by Git.
- [ ] Create branches according to the instructor's requirements and make meaningful commits.
- [ ] Push the repository and verify GitHub Actions on Ubuntu, Windows, and macOS.
- [ ] Create a Pull Request titled `lab1/finish`.
- [ ] Complete `docs/ai-log.md` with actual prompts and results.
- [ ] Add genuine screenshots and links to GitHub Actions runs and the demonstration video.
